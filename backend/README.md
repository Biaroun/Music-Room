# Music Room — Backend

API NestJS de Music Room (REST + Socket.IO, PostgreSQL, Redis).

La documentation complète (installation, configuration, API, sécurité) est dans le [README principal](../README.md).

```bash
npm install
npm run start:dev    # http://localhost:3000, Swagger sur /api/docs
npm test             # tests unitaires
npm run test:e2e     # tests e2e (Postgres + Redis requis : make docker-up)
```
